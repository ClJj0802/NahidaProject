# Summary
User reports indicate significant variance in GPT-SoVITS v2 ProPlus inference speed across different GPU architectures. High-end NVIDIA GPUs (RTX 4090) demonstrate real-time factors (RTF) as low as 0.014, while mid-range cards (RTX 4060 Ti) and CPUs show RTF values closer to 0.5. Unverified optimizations like CUDA Graphs are discussed but lack public implementation details [S1].

# Confirmed Findings
*   High-end hardware (RTX 4090) achieves RTF of 0.014, processing 1400 words in 3.36 seconds.
*   Mid-range hardware (RTX 4060 Ti) exhibits an RTF of 0.028 [S2].
*   Apple M4 CPU performance reported at RTF 0.526 [S1].
*   Token prediction speeds observed around 150 iterations per second [S1].

# Likely Findings
*   Parameter tuning (e.g., `text_split_method`, `batch_size`) influences first response latency, potentially reducing it to 0.339–0.443 seconds [S1].
*   Total processing times vary widely based on sentence length and hardware, ranging from 1.363s (short sentences) to 3.36s (longer Chinese sentences) [S1].
*   Enabling `streaming_mode` or `parallel_infer` may impact latency, though specific results are unverified [S1].

# User Reports
Users report inconsistent RTF values on similar hardware, questioning reproducibility. Some report Total RTF between 1.363 and 1.719 under load [S1]. One user noted RTF 1.531 on an RTX 3090 for short Korean sentences [S2].

# Recommended Experiments
*   **Proposed:** Test CUDA Graph implementation to reduce overhead, pending code availability.
*   **Proposed:** Benchmark `streaming_mode` vs. batch inference to determine latency benefits.
*   **Proposed:** Validate parameter optimizations (`text_split_method`) across different language inputs.

# Hardware Relevance
Performance scales heavily with GPU architecture. RTX 4090 is significantly faster than RTX 4060 Ti or M4 CPU. No data exists for RTX 5060 Ti or Ryzen 7500X3D configurations in these reports [S1].

# Confidence
Low to Medium. Findings rely on anecdotal GitHub comments without independent verification. Specific optimizations lack documented implementation [S1].
